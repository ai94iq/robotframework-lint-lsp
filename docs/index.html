Two parts, one loop.

Auto-fix hook

After every Edit or Write on a .robot or .resource file, robotframework-lint-autofix runs robocop's safe fixes: Set Test Variable and Create List become VAR, old [Return] and Run Keyword If become RETURN and IF, one assignment style per file. It prints nothing and never blocks the edit.

Language server

robotframework-lint-lsp lints the buffer with the robocop defaults plus six RF 7.5 rules. It sends warnings and errors only, at most 20 per file, one line each, and answers keyword definition, references, hover and symbols.

SettingDefaultWhat it does
maxDiagnostics20Findings per file, then one overflow line with the count cut.
minSeveritywarningFloor: info, warning or error. Fixable Info rules are raised to warning.
select, ignore[]Robocop rule ids to keep or drop.
groupFindingsfalseOne diagnostic per rule. Off: it left more findings unfixed in tests.
