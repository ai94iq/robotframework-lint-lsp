Edit, fix, report.

  1. Agent edits

    The agent writes or edits a .robot or .resource file.

    PostToolUse

  2. Auto-fix hook

    Robocop's safe fixes run on the file. It prints nothing.

    didChange

  3. LSP lints

    Robocop defaults plus the RFL rules, warnings and up, at most 20.

    short lines

  4. Diagnostics pushed

    One line per finding, 120 characters at most, with a fix hint.

    next turn

  5. Agent fixes the rest

    Only what robocop cannot fix reaches it, such as long keywords.

Before you trust it on your repo.

  • Run the same task on your own suites. One task is one data point.
  • Confirm the hook runs: claude --debug shows PostToolUse with robotframework-lint-autofix and status 0.
  • Count leftover issues with robocop check on the final files, not from the chat.
